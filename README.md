## Salut 👋

Je suis ingénieur bâtiment, basé à Paris. Au quotidien, je suis les chantiers d'aménagement de magasins pour une boîte danoise : plannings, sous-traitants, budgets, et pas mal d'imprévus.

À côté, je code des petits outils qui me servent sur le terrain. J'aime bien faire parler les chiffres (comparatifs, tableaux de bord), je traîne dans le Web3 depuis 2024 et j'écris de temps en temps des articles sur les projets que je suis.

### Ce sur quoi je bosse

**[Studio Modelis](https://github.com/RedBubblyBubble/studiomodelis-fr)** : le site que j'ai construit pour Studio Modelis, du scan 3D Matterport pour les architectes, les bureaux d'études et les enseignes. Next.js, TypeScript et Tailwind.

**Warcha** (repo privé) : un outil pour les entreprises du second œuvre. Je travaille en ce moment sur un module qui génère les PV de mise en œuvre, un document que j'ai trop souvent dû rédiger à la main sur mes chantiers.

**[landing-page](https://github.com/RedBubblyBubble/landing-page)** : une landing page intégrée à partir d'une maquette Figma, surtout pour m'entraîner à coller au pixel près.

### Le côté Web3

J'ai commencé par les testnets : Swisstronik, Polymer, Avail, Celestia, Babylon, Sonic… Déployer des contrats, tester, remonter des bugs. C'est comme ça que j'ai appris Solidity et Hardhat.

Les repos de cette période sont archivés, mais toujours là si ça vous intéresse : [un token ERC-20](https://github.com/RedBubblyBubble/Swisstronik-2), [un NFT ERC-721](https://github.com/RedBubblyBubble/Swisstronik-3) et [des contrats cross-rollup avec Polymer](https://github.com/RedBubblyBubble/Polymer-testnet).

### Mes outils

Next.js, TypeScript, Tailwind, Solidity, Hardhat, Figma… et beaucoup (trop) d'Excel.
