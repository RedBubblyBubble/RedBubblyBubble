# Salut, moi c'est RedBubblyBubble 👋

**Ingénieur bâtiment** basé à Paris, je travaille dans le **retail** pour une société danoise.
À côté, je construis des outils web autour du bâtiment, j'analyse des données et j'explore le **Web3** depuis 2024 en testant des protocoles en avant-première.

- 🏗️ **Bâtiment & retail** — conception, suivi de chantier, déploiement de points de vente
- 📊 **Data & finance** — analyses de données, comparatifs financiers, tableaux de bord
- ⛓️ **Web3** — testnets, déploiement de smart contracts, suivi de projets early-stage
- ✍️ **Rédaction** — articles d'analyse sur des projets Web3
- 📍 Paris · 🇫🇷 / 🇬🇧
